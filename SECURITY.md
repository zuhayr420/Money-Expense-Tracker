# Security Policy

## Supported Versions

We release security updates and patches for active versions of Verdela Money Expense Tracker:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The project team and contributors take security very seriously. If you discover a vulnerability or potential security risk in this application:

1. **Do not disclose the issue publicly** (e.g., via GitHub Issues, public pull requests, or social media).
2. **Submit a private advisory**: Use GitHub's private vulnerability reporting feature on the repository:
   - Navigate to the **Security** tab of this repository.
   - Click **Report a vulnerability**.
3. **Alternatively, email the maintainer**:
   - Send details to `zuh1234ayr@gmail.com`.
   - Please include:
     - Type and nature of the issue.
     - Step-by-step reproduction instructions or proof-of-concept.
     - Potential impact of the vulnerability.

## Response SLA

- **Initial Response**: Within 48 hours acknowledging receipt of the report.
- **Triage & Assessment**: Within 5 business days with an impact assessment.
- **Fix & Patch**: Critical vulnerabilities will be prioritized and resolved with a patch release as soon as possible.
- **Credit**: Researchers and reporters adhering to responsible disclosure will be credited in release notes.
